## Regra de publicação

Arquivos dentro de `docs/marketing/` são fontes de trabalho e documentação. Eles não são publicados pelo site. Um asset só deve ir para `site/public/` quando for necessário em produção e estiver pronto para se tornar publicamente acessível.
