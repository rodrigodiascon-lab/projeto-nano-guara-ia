## guara.bot official mascot

The approved and canonical visual identity of **guara.bot** is the floating third option documented in:

- `docs/marketing/brand/guara-bot/README.md`
- `docs/marketing/brand/guara-bot/guara-bot-concept-floating-v3.png`

For every image, illustration, animation, mockup, or visual asset that includes guara.bot:

1. Read the brand document before creating the asset.
2. Use `guara-bot-concept-floating-v3.png` as the required identity reference.
3. Preserve the mascot design. Do not reinterpret, redesign, or replace its defining features unless the user explicitly requests and approves a redesign.
4. Keep the circular guaraná head, single leaf, red face disk, cream ring, graphite expressive visor, floating seed-shaped body, short rounded arms, legless silhouette, proportions, satin materials, and official palette.
5. Write the name exactly as **guara.bot**, all lowercase and without an accent. When the chest is visible, keep the name centered once on the chest with a clearly visible dot.
6. Never use the exploratory v1 or v2 concepts as the character identity. They are historical alternatives only.

Pose, expression, framing, lighting, background, and scene may change to fit the requested asset, but the mascot identity must remain consistent with the approved v3 reference. A client brand may appear only through discreet secondary accents unless the user explicitly authorizes a broader adaptation.

Because generative image tools can introduce visual drift, prefer reference-based generation or editing and explicitly list the identity invariants in the prompt. Validate every output against the approved v3 image before delivery. If an output changes the mascot design, reject it and regenerate or correct it.
