# Vídeos

Projetos-fonte de vídeo da nanoguará.ia. Cada formato vive em uma pasta independente e contém briefing, direção visual, plano de cenas e configuração do HyperFrames.

## Projetos

| Pasta | Formato |
|---|---|
| [`guara-bot-meta-ads-feed/`](guara-bot-meta-ads-feed/) | Feed de Meta Ads |
| [`guara-bot-meta-ads-story/`](guara-bot-meta-ads-story/) | Story/Reels de Meta Ads |

## Fluxo de trabalho

Entre na pasta do formato e use:

```bash
npm run dev
npm run check
npm run render
```

Leia o `AGENTS.md` da pasta antes de editar. O design do mascote deve seguir a referência canônica em [`../docs/marketing/brand/guara-bot/README.md`](../docs/marketing/brand/guara-bot/README.md).
